# 输出脱敏清单

Skill 输出（判定、结论、证据链、报告）在对外展示前，按下表逐类脱敏。原则：**保留排查所需的结构与量级，抹掉可定位到具体环境的信息**。

| 类别 | 原始形态 | 脱敏后形态 | 说明 |
|------|----------|------------|------|
| SQL 语句 | `SELECT * FROM t_order WHERE create_time > '2026-08-15 10:00:00'` | `SELECT * FROM t_biz_order WHERE status=? AND create_time>?` | 表名/字段名可保留语义结构，参数值一律 `?` 化 |
| IP 地址 | `10.20.31.247:3306` | `db-host:3306` | 主机 IP 换语义占位名，端口保留（排查需要） |
| 主机名 | `prod-mysql-03.internal` | `db-host` / `redis-host` | 同上；真实环境拓扑关系不外泄 |
| 服务名 | 内部微服务实名 | `order-svc` / `cart-svc` / `member-svc` | 保留调用方向语义即可 |
| traceId | `a3f9c2e1b8d74f6a...`（32 位） | `demo.trace.001` 或截断前 8 位 | 读者无法回查生产系统，保留"可引用"的形态 |
| 用户/账号 | 手机号、账号 ID、内部邮箱 | 一律不出现在输出中 | 排查性能问题不需要，见即删 |

## 使用方式

- `analyze.py` / `os_empirical.py` 的输出在进入报告（`templates/report.md`）前按本清单过一遍；
- 案例复现素材（`cases/` 目录）已在入库前完成同等脱敏，读者可直接使用；
- 发布（博客、公众号、对外报告）时以本清单为准，逐条自查后再发。
